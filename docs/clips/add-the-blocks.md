# Clip script — Add the blocks

Recording script for the clip on `guide-add-the-blocks.html` and on step 2 of
`process-map-the-farm.html`. Not published.

- **Target length:** 9 minutes. Four routes, so it is the longest clip in this
  process. Record it as four separate takes and cut them together.
- **Recording account:** tenant `green-valley`, on the farm created in the
  previous clip.
- **Prepare before recording:** the block layout you will draw, the codes you
  will type, and one AOI file set for the upload take.

---

## Before you press record

Same checklist as the farm-creation clip: 1440 × 900, zoom 100%, one tab, no
notifications, large cursor. Plus:

| Check | Why |
| --- | --- |
| The farm exists and fills the map | The Add menu acts on the open farm. |
| Decide the codes in advance | Typing and thinking at the same time reads as hesitation. |
| Have the AOI files ready in one folder | Take 4 needs them within one drag. |
| Delete any test blocks first | The clip should start from a farm with no blocks. |

---

## Take 1 — draw one block (0:00 to 2:30)

**Say:** "A block is the area you manage as one thing. It carries the crop, the
plan, and the person responsible, and every index number is reported against
it. The farm gave us the outline. Now we cut it into the parts we actually
work."

**Do:** open the **Add** menu. Point out the four routes without using them
yet: Draw block, Draw pivot, Auto-block grid, Upload AOI files.

**Say:** "Pick by how the farm is laid out, not by habit."

**Do:** choose **Draw block**. Draw one block. Show the hint bar text. Type the
code, leave the name empty, create it. Draw a second one beside it.

**Say, while drawing the second:** "Blocks must not overlap. If two blocks share
ground, that ground is counted twice, once in each block."

---

## Take 2 — draw a pivot (2:30 to 4:30)

**Do:** **Add** → **Draw pivot**. Click the centre, then the radius.

**Say:** "For a centre pivot, do not trace the circle by hand. Click the centre,
then set the radius. AgriPulse draws the circle."

**Do:** show the radius and area in the panel. Then change **Sectors** from 1 to
4, then to 8. Let the preview update on screen.

**Say:** "Sectors cut the circle into equal slices, and each slice becomes its
own block. One sector means the whole pivot is a single block. Eight sectors
means you can see which arm of the pivot is failing, instead of one average
that hides it."

**Do:** settle on a sensible number, type the code, create.

---

## Take 3 — auto-block grid (4:30 to 6:30)

**Do:** **Add** → **Auto-block grid**. Set the cell size in metres, compute
candidates, deselect a few, create the rest.

**Say:** "For a regular field with no natural divisions, let the app cut it.
Set the cell size, compute the candidates, then keep the ones you want. You do
not have to take them all."

**Say, as a callout:** "This is not the same thing as the grid inside a block.
This creates blocks. The sub-block grid divides one block into smaller cells for
detail inside it, and that is a farm-level setting we cover later."

---

## Take 4 — upload AOI files (6:30 to 8:30)

**Do:** **Add** → **Upload AOI files**. Drag a folder of files in. Show the rows,
the codes, and a row marked Reuse or Replace.

**Say:** "If a surveyor already gave you the blocks, upload them. GeoJSON, KML,
or a shapefile in a zip. One polygon per block."

**Say, on the replace row:** "A row that matches a block you already have is
marked Replace, and it needs a tick to confirm. The old block is deleted if it
is empty, and deactivated if it has history. That is not something to click
past."

**Do:** create, then show the result line: created, replaced, reused, errors.

---

## Take 5 — check the layout (8:30 to 9:00)

**Do:** zoom out to the whole farm.

**Say:** "Last step, and it is the one people skip. Add the block areas up and
compare with the farm. The difference should be the roads and buildings you
have not marked yet. Look for gaps and overlaps now, because blocks carry crops
and history, and moving them later costs more."

**Say to close:** "Next we set the grid cell size, and mark the land units."

---
