Taxonomy and cultivars

A crop has a dotted path. A decision tree, a plan template or a report can aim at any level of it. This is how one library serves a farm growing six mango cultivars with different calendars.

How a path is read

  • mango matches every mango block.
  • mango.sukkary matches only that cultivar.
  • mango.alphonso.short matches a named strain inside a cultivar.
  • An empty crop path means the rule runs on any crop.

Canopy size classes

Tree crops also carry a size class: small, medium or large. It changes what a rule expects to see from a block of young trees against a block of mature ones.
