Scouting signal catalog

Nine signal definitions and five forms are seeded for every tenant. They are the shared vocabulary of the field: without them there is no form for the phone app to render.

Rules the engine enforces

  • Mean, maximum, minimum and sum work on numbers only.
  • Count works on any kind, because it counts rows.
  • Anything else falls back to latest. A form that asks for maximum on a category is treated as latest.

Tenant signals

A tenant can author its own signal definitions. A tenant row with the same code as a shared one takes priority for that tenant. The shared catalog is not changed.
