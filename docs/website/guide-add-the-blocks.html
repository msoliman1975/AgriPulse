Guide · Process 01

Add the blocks

A block is the area you manage as one thing. It carries the crop, the plan and the person responsible, and it is the unit every index number is reported against. The farm gives you the outline. Blocks are what you work with.

Who does this

Farm manager, tenant admin

How long it takes

10 minutes for a few blocks, an hour for a large farm

Step by step

Add the blocks

Open the Add menu

  • Open the farm in Farm management and use the Add menu on the map toolbar.
  • It offers four ways in: Draw block, Draw pivot, Auto-block grid, and Upload AOI files.
  • Pick by how the farm is laid out, not by habit. A pivot farm should use Draw pivot. A farm you already have files for should use the upload.

Route 1 — draw one block

  • Choose Draw block. The hint bar reads Drawing block — click to add points, double-click to finish.
  • Click each corner, double-click the last one. The panel opens with the area already calculated.
  • Code is required, for example B-12. Name is optional, for example North strip.
  • Click Create block. Repeat for the next block.
Note

Blocks may not overlap. If two blocks share ground, every number for that ground is counted twice, in both blocks.

Route 2 — draw a pivot

  • Choose Draw pivot. The hint bar reads Drawing pivot — click the centre, then click to set the radius.
  • Click the pivot centre, then click once more to set the radius. The panel shows the radius in metres and the area.
  • Sectors (equal slices) splits the circle into equal wedges. The presets are 1, 4, 6, 8 and 12, and you can type another number.
  • One sector means the whole circle is a single block. Four or more gives you a block per wedge, which is how you spot a failing arm of the pivot.
  • Code is required, for example P-3. Click Create pivot.

Route 3 — auto-block grid

  • Choose Auto-block grid when the farm is a regular field with no natural divisions.
  • Set the cell size in metres and click Compute candidates. The farm is cut into equal squares and each one is offered to you.
  • Select the candidates you want. You do not have to take them all.
  • Click Create selected blocks.
Note

This is a different thing from the grid inside a block. Auto-block grid creates blocks. The sub-block grid divides one block into cells for within-block detail, and it is set per farm.

Route 4 — upload the files

  • Choose Upload AOI files and drop the files in. It accepts .geojson, .json, .kml, and a shapefile in a .zip. One block per polygon.
  • Each row gets a code and an optional name. Fix any code the upload flags.
  • A row that matches an existing block is marked Reuse or Replace. Replacing needs a tick to confirm, because the old block is deleted if it is empty and deactivated if it is not.
  • Click Create N blocks. The result line reports created, replaced, reused and errors.

Check the layout

  • Add the block areas up and compare against the farm area. The difference should be the roads, buildings and canals you have not marked yet.
  • Look for gaps and overlaps on the map, at the zoom you drew at.
  • Fix the shapes now. Blocks carry crops, plans and history, so moving them later costs more.
Check it worked
  • Every area you manage has a block, and no two blocks overlap.
  • The block areas add up to about the farm area, less the roads and buildings.
  • Each block shows the code your team uses in the field.

When it does not work

What you seeWhat it means
Could not create, check the code is uniqueAnother block on this farm already uses that code.
Code is requiredThe Create button stays disabled until the code has something in it.
Outside EgyptAn uploaded polygon falls outside the country bounds. The file is in the wrong coordinate system, or the wrong file.
No polygon foundThe file has no polygon in it. A points-only KML will not do.
Unsupported file typeUse .geojson, .json, .kml, or a shapefile inside a .zip. A bare .shp is missing its sidecar files.
Duplicate code in uploadTwo rows in the same upload carry the same code. Codes must be unique within the batch as well as on the farm.
Replace not confirmedA row would replace an existing block. Tick the confirmation, or change the code so it creates a new block instead.
