07  Decision 6 — dark mode: in or out?

Nothing in the codebase anticipates this today; ap.* are literal hex values in tailwind.config.ts. If dark mode is wanted, the tokens must become CSS variables during this pass — retrofitting means touching every file a second time. The dark values below are a first pass, not a finished palette.

My read: defer it, but make it cheap. Nobody has asked for dark mode, and the primary use context — a tablet in daylight — argues for light. But moving ap.* to CSS variables in phase 0 costs almost nothing and makes the answer reversible later. Committing to ship dark mode now is the expensive part; committing to not foreclose it is free.
