What history buys

          

            
Reports resolve a value as of the period end, not as of now —
              the latest log row at or before until, falling back to the current value when no log row
              precedes the period.

            
A Q1-2026 crop-health report shows age_at_transplant_months = 30 for
              B-04, even though the field reads 42 today. Without the log the report would silently
              back-date today's number.

          

        

      

    

    

      The v1 staleness gap. No derived type ships in v1, so a stored age never ages —
      the two edits above are manual. transplant_date is seeded next to the age so a later
      derived type (or a days_since() key) computes current age with no data
      migration.

Authoring warning

          

            
A tree targeting [mango] that references
              seed_tuber_grade (potato-only) evaluates to None forever, silently. The
              validator warns at authoring time — it does not hard-fail, since a tree may legitimately target
              several crop paths.
