What the new designer changes the five concepts

An old tree walks to one leaf, and that leaf says everything. A new tree walks past several findings and folds them at the end. Five concepts carry this.

set
Writes one or more variables. Use it to load the band for the recorded tree size once, instead of repeating the numbers in every branch.
switch
Ordered cases, first match wins, and a default is required. This replaces a chain of two-way condition nodes.
register
Records one finding code with a severity of info, warning, or critical, then carries on walking. One walk can register several findings.
stop
Ends the walk and starts the fold. Every path must reach a stop, or the tree does not publish.
combinations
A list of rules. Each rule names an exact set of finding codes and gives the card text, the action type, and one status of very_good, good, issue, alert, or na.

Two limits shape every rule on this page. A rule matches the finding set of a single walk, so two findings join into one card only if the same tree registered both. A rule matches the whole set exactly, so a tree that can register 4 findings needs a rule for every set those 4 can form, minus the sets the stage gates make impossible.

Flowering and fruit programmango_flowering_program · block What is due in the flowering and fruit-set part of the season? In pre-flowering it uses canopy greenness against the block's own history to decide whether the vegetative flush has stopped, then says hold or start the 50 to 60 day dry period. It also warns when the canopy is well-watered while the forecast is cool, which pushes a flush instead of flowers. Through fruit set and fruit development it gives the due half of the KNO3 and thinning program.

  • fruit_program_late_due NEW the second KNO3 spray and the bulking irrigation are due

Decisions still open 8 items

Cell scope or block scope

30 of the 31 old trees run per block. Only t_water_stress_confirm runs per cell. This page puts the three measured trees at cell scope and the four calendar or weather trees at block scope. Mixing scopes means a grower sees cell cards and block cards on the same screen.

The canopy tree reads water and nutrition indices too

A combination rule matches one walk, so the canopy tree cannot read the water tree's findings. To name the cause of a weak canopy it registers dry and nutrient_low itself. The same index is then read by two trees, and the two cards can disagree.

A clause may not contain a comma

The API refuses a finding clause with a comma in it: a clause is one fragment the card joins to others, so two ideas mean two findings. Three of the 14 new clauses had to be rewritten before they were accepted. Plan for it when adding more.

ndvi_low and vigour_low say the same thing

Both clauses read "canopy vigour is below the band for this tree size", word for word. Two codes for one meaning split the finding set and break rule matching. One should be retired before the new trees are written.

MSI and EVI are dropped

MSI measures the same thing as NDMI on an inverted scale, and keeping both lets one signal vote twice in the fold. EVI is a fourth view of the vigour question the size switch already answers with MSAVI, SAVI and NDVI. Neither is read by any of the seven. Dropping them removes two cards that fire today.

Absolute bands or z-scores

26 of the 31 old trees compare against an absolute band keyed on tree size. 5 compare against a z-score on the block's own history. Each proposed tree mixes both: bands for the per-index findings, z-scores for the joining question. A z-score needs 3 samples in a 15-day day-of-year window, so it returns nothing on a new block.

ndvi_baseline_alert_v1 targets any crop

That tree has an empty crop path, so it also fires on mango blocks and says the same thing as the canopy tree. It is not counted in the 31. Decide whether it keeps running on mango or gets a crop path that excludes mango.

Cutover of the 23 active trees

A beta tree carries stage beta and the nightly sweep reads stage live, so the new trees run on nothing until the sweep is switched. The 23 active old trees keep firing until they are deactivated one by one.
