How a row was placed

  1. If the register's status says the code is already merged, written, in review, or only needs verifying, the row goes to tier 1.
  2. If the status says blocked, deferred, parked, or decision needed, the row goes to tier 5.
  3. Otherwise: size S with no dependency goes to tier 2, size S with a dependency to tier 3, size M with no dependency to tier 4, everything else to tier 5.
